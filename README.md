# BODIK ODCS (data-bodik-jp)

BODIK ODCS is a organization open-data portal for Japan running **CKAN**, exposing a standardized catalog API over ~17,545 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-bodik-jp/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-bodik-jp-api-evangelist&utm_content=repo)

## Type
- **kind:** organization  ·  **software:** CKAN

## API
- **BODIK ODCS CKAN Action API** — base `https://data.bodik.jp/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.bodik.jp)
- Live endpoint verified: `https://data.bodik.jp/api/3/action/package_search?rows=0` · ~17,545 datasets
